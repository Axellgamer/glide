      Help

      Four steps, no terminal, nothing installed on your computer. If this page is already open at /console/ inside your codespace, you are connected and can skip the connect step.

      1. 1

        Open the repository in a codespace

        On GitHub, choose Code → Codespaces → Create codespace. The container installs everything by itself.

      2. 2

        Wait for the session to start

        The console boots the display, the stream and Minecraft automatically. Nothing to run.

      3. 3

        Leave port 6080 private

        That is the default and it is the safe setting. The stream opens in its own tab while you are signed in to GitHub, so no public port is needed.

      4. 4

        Paste the URL here

        Copy the 6080 URL from the Ports tab and paste it into Connect. Then press Open stream on Session.

      The port asks for a GitHub sign-in

      Private ports cannot be embedded, which is fine: use Open in a new tab and stay signed in to GitHub. Do not make the port public.

      The video is blank or still loading

      The stream answered, but Minecraft is still downloading. Watch the log panel on Session (source: launcher); the session is ready when the progress reaches the end.

      Keyboard or mouse does nothing

      Click once inside the stream tab so it can capture the pointer. If the Selkies dashboard is visible, use its keyboard capture button.

      It is slow

      Codespaces are not gaming PCs. Use the low profile, 854 × 480, and install optimisation mods in Installations. A 4-core codespace is a big step up.

      Where are my worlds and mods?

      Mods live in the repository under Files → Repository → Client/mods/<version>/<loader>. Worlds and settings live in Files → Minecraft data.

      Does this need a token, Actions, or anything installed?

      No. There is no GitHub token, no workflow run and no local install. The browser talks to the codespace you already opened, and only that URL is stored.

      Stopping the codespace

      Stop session stops the game and the stream. Then stop the codespace itself from the GitHub Codespaces page so it does not keep using core hours.

      Codespaces are for developing and testing the project. A public desktop stream is not a loophole around that; keep sessions short and run it on your own account.
